# 头像引擎 · 宝塔面板部署步骤

> 适用环境：宝塔面板 + Nginx + MySQL 5.6 + PHP 8.2 + Redis 5.0+
> 代码中各配置读取方式均已核实，按本文步骤操作即可完成部署。

---

## 一、安装环境（软件商店）

| 软件 | 版本 | 必装扩展 |
|---|---|---|
| Nginx | 任意稳定版 | — |
| MySQL | 5.6 | — |
| PHP | **8.2** | redis、fileinfo、curl、mbstring、openssl、gd |
| Redis | 5.0+ | — |
| 进程守护管理器 | — | 守护队列 Worker |

**PHP 扩展安装**：宝塔 → 软件商店 → PHP 8.2 → 设置 → 安装扩展 → 勾选 `redis` 和 `fileinfo`（上传检测必需），`gd` 用于缩略图生成。

---

## 二、上传代码

上传整个项目到 `/www/wwwroot/myradar.cn/`，最终结构：

```
/www/wwwroot/myradar.cn/
├── backend/    # 后端（网站运行目录指向 backend/public）
├── admin/      # 管理后台 SPA
├── frontend/   # 官网静态资源
└── storage/    # 上传/日志/缓存（需可写）
```

---

## 三、创建数据库

宝塔 → 数据库 → 添加数据库：

- 数据库名：`avatar`
- 用户名：`avatar`
- 密码：自设
- 字符集：`utf8mb4`

然后导入建表脚本（phpMyAdmin 或终端）：

```bash
mysql -uavatar -p'你的密码' avatar < /www/wwwroot/myradar.cn/backend/database/migrations/001_init.sql
```

导入后自带管理员账号：**admin / admin123**（首次登录后立即修改密码）。

---

## 四、创建站点 + 伪静态配置

> 采用宝塔图形化界面配置，**不需要手动改 Nginx 配置文件**。

### 4.1 创建站点

宝塔 → 网站 → 添加站点：

- 域名：填你的域名
- 根目录：`/www/wwwroot/myradar.cn`
- PHP 版本：8.2
- 数据库：不创建（第三步已建好）

### 4.2 设置运行目录

站点设置 → 网站目录 → **运行目录** 改为 `/backend/public`，保存。

### 4.3 粘贴伪静态规则

站点设置 → **伪静态** → 粘贴 `deploy/宝塔伪静态.conf` 的全部内容 → 保存。

该规则包含：

- `/uploads/` → `storage/uploads/`（用户头像静态访问）
- `/admin/` → `admin/`（管理后台 SPA）
- `/static/` → `frontend/`（官网静态资源）
- 其他全部请求 fallback 到 `index.php`（框架路由）
- 拦截 `.git/.env` 及 `storage/app/core/config` 等敏感目录

> 伪静态里**不能**写 `server{}`、`root`、`fastcgi_pass`、`fastcgi_param`：宝塔的 PHP 解析配置（`enable-php-82.conf`）已自带 fastcgi 参数，在伪静态里再加 `fastcgi_param` 反而会导致整套环境变量不继承。因此密码/密钥不走 nginx，按下面两步配置。

### 4.4 配置数据库和 Redis 连接

直接改两个配置文件（代码支持文件配置，无需环境变量）：

**`backend/config/database.php`**：

```php
return [
    'host'     => '127.0.0.1',
    'port'     => '3306',
    'database' => 'avatar',
    'username' => 'avatar',
    'password' => '第三步设置的数据库密码',
    'charset'  => 'utf8mb4',
];
```

**`backend/config/redis.php`**：

```php
return [
    'host'     => '127.0.0.1',
    'port'     => 6379,
    'password' => 'Redis有密码则填，没有留空',
    'database' => 0,
    'prefix'   => 'avatar_',
];
```

改完后在宝塔文件管理中确认这两个文件权限为 644、属主 www。

### 4.5 配置 JWT 密钥（重要）

JWT 密钥代码只读环境变量 `APP_JWT_SECRET`，通过 PHP-FPM 进程池注入：

宝塔 → 软件商店 → PHP 8.2 → 设置 → **配置文件**（php-fpm 的 www.conf），在文件末尾追加：

```ini
env[APP_JWT_SECRET] = '换成一段随机长字符串'
env[APP_DEBUG] = '0'
```

然后点「重启」PHP。

> - 生产环境 `APP_DEBUG=0`；排错时可临时改 `1` 看错误详情，事后改回。
> - 生成一段随机密钥：宝塔终端执行 `openssl rand -hex 32`，把输出粘进去。
> - 队列 Worker 是 CLI 进程不读 FPM 配置，但 Worker 不签发 JWT，无需配置。

## 五、目录权限

宝塔终端执行：

```bash
chown -R www:www /www/wwwroot/myradar.cn/storage
chmod -R 755 /www/wwwroot/myradar.cn/storage
```

`storage/uploads` 是本地上传/生成头像的存放目录，Nginx 已在配置中映射 `/uploads/` 到此处。

## 六、配置豆包 API Key

> **注意**：`ArkApiService` 从 `Config::get('api', 'ark_api_key')` 读取（数据库 `site_settings` 优先于 `config/api.php`），**不读环境变量**，nginx 里的 `ARK_API_KEY` 可忽略。

两种方式任选其一：

- **方式 A（推荐）**：登录管理后台 `https://你的域名/admin/` → 左侧菜单「API 生图」→ 填入豆包 API Key（修改后需重启队列 Worker 生效）
- **方式 B**：直接改 `backend/config/api.php` 的 `ark_api_key`

---

## 七、启动队列 Worker（关键，否则生成任务不会执行）

宝塔 → 软件商店 → 进程守护管理器 → 添加守护进程：

| 配置项 | 值 |
|---|---|
| 名称 | avatar-worker |
| 运行用户 | www |
| 启动命令 | `/www/server/php/83/bin/php /www/wwwroot/myradar.cn/backend/bin/worker.php avatar:generate --timeout=30 --max=100000` |
| 进程数量 | 1~2（生成量大可加） |

Worker 会阻塞消费 `avatar:generate` 队列：调豆包 → 转存 → 生成缩略图 → 入池。

> 建议同时在宝塔「计划任务」添加 Shell 脚本（每 5 分钟），自动修复卡死/pending 超时任务：
> `sudo -u www /www/server/php/83/bin/php /www/wwwroot/myradar.cn/backend/bin/repair.php`

## 八、验证

按顺序访问验证：

1. `https://你的域名/` — 官网首页正常渲染
2. `https://你的域名/admin/` — admin / admin123 登录后台（后台入口为 `admin/index.php`，伪静态已配置 PHP 解析；若后台页直接下载 PHP 文件或空白，检查伪静态中 `/admin/` 内嵌套的 `fastcgi_pass` sock 是否与实际 PHP 版本一致）
3. `https://你的域名/robots.txt` 和 `/sitemap.xml` — SEO 端点
4. 官网注册账号 → 控制台 → 提交一次生成 → 观察积分扣减、Worker 日志、`storage/uploads/avatars/` 是否产出图片
5. 后台「生成记录」确认状态流转：pending → processing → success

## 附：常见问题

| 问题 | 排查方向 |
|---|---|
| `nginx: [emerg] duplicate location "/uploads/"` | 规则被同时粘贴进了「配置文件」和「伪静态」两处。配置文件里删除所有手动粘贴的 `location` 块（只保留 root、`include enable-php-82.conf`、日志），路由规则只保留在「伪静态」tab，然后 `nginx -t` 验证 |
| 页面 500 | 看 `storage/logs/`；临时在 PHP-FPM 配置 `env[APP_DEBUG]='1'` 重启看错误详情，定位后改回 0 |
| 所有页面都 404 / 只有首页能开 | 伪静态未粘贴或运行目录未设为 `/backend/public` |
| 生成任务一直 pending | Worker 未启动或未守护；检查进程守护管理器日志 |
| 头像图片 404 | 检查伪静态 `/uploads/` 的 alias 路径与 `storage/uploads/` 是否对应；项目是否上传在 `/www/wwwroot/myradar.cn/` |
| 后台 /admin/ 刷新 404 | 伪静态中 `/admin/` 的 `try_files` 规则丢失，重新粘贴 `宝塔伪静态.conf` |
| redis 扩展报错 | PHP 8.2 未安装 redis 扩展，回到第一步安装 |
| 登录态失效/重启后掉线 | JWT 密钥未配置或被重置；检查 PHP-FPM `env[APP_JWT_SECRET]` |
| 充值/支付无响应 | 未配置支付参数，默认回退人工核销；到后台 payment 分组填写商户信息 |
