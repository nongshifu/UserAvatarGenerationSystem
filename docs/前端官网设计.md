# 前端官网与生成流程设计

> 技术栈：**PHP 模板渲染 SSR**（由 backend 自写视图层直出 HTML），前端静态资源放 `frontend/` 目录  
> 部署路径：根域名 `/`  
> SEO：PHP 直出 HTML + sitemap + 结构化数据，无需 Node 环境

---

## 二、首页设计

### 2.1 视觉风格（AI 气质）
- 深色渐变背景 + 动态光晕/粒子动画
- 毛玻璃（glassmorphism）卡片
- 主色调：紫色 → 蓝色渐变（AI 科技感）
- 字体：无衬线 + 大号标题

### 2.2 页面结构
```
┌─────────────────────────────────────┐
│  导航栏：LOGO │ 首页/分类/文档 │ 登录  │
├─────────────────────────────────────┤
│  Hero 区：                            │
│  大标题「AI 头像生成引擎」            │
│  副标题                                │
│  [立即体验] [查看文档]                │
├─────────────────────────────────────┤
│  测试生成区（对接管理员预设KEY）       │
│  [上传图片] → 选风格/颜色/形状 → 生成 │
│  限制：需图形验证码 + IP 限流          │
├─────────────────────────────────────┤
│  随机头像分类展示                      │
│  Tab: 全部 | 卡通 | 赛博朋克 | ...    │
│  瀑布流/网格头像列表                   │
├─────────────────────────────────────┤
│  特性介绍：一键生成 / API 开放 / 头像池│
├─────────────────────────────────────┤
│  Footer：备案、链接                    │
└─────────────────────────────────────┘
```

### 2.3 SEO 要素
- `<title>` 动态渲染
- `<meta name="keywords/description">`
- Open Graph 标签
- JSON-LD 结构化数据（Organization / ImageObject）
- 图片 `alt` 属性
- 语义化 HTML

## 三、用户控制台

### 3.1 生成头像流程
```
1. 上传图片（拖拽/点击）
   ↓ 预览原图
2. 选择风格（卡片网格）
3. 选择颜色（色板）
4. 选择形状（图标）
5. 勾选「加入公共头像池」（默认勾选）
6. 显示消耗积分 + 当前余额
7. 点击生成
   ↓
   扣积分 → 异步生成 → 进度提示
   ↓
   展示结果 → 可下载/重新生成
   ↓
   自动入三池
```

### 3.2 KEY 管理
- KEY 列表（脱敏展示）
- 创建 KEY（名称、QPS、日限额）
- 创建后仅展示一次完整 Key
- 重置 / 禁用 / 删除

### 3.3 充值
- 套餐卡片列表（价格、积分、赠送）
- 选择支付方式（微信/支付宝）
- 扫码支付 → 回调更新

### 3.4 我的头像
- 按时间倒序（新的在上）
- 网格展示
- 查看详情 / 下载 / 删除

## 四、认证流程

### 4.1 注册
```
填写 邮箱 + 密码 + 确认密码
→ 发送验证邮件（可选）
→ 创建用户
→ 赠送注册积分（point_logs 写入）
→ 自动登录
```

### 4.2 登录
```
邮箱 + 密码
→ 校验
→ 下发 JWT + refresh token
→ 跳转控制台
```

---

## 五、首页测试生成限制策略

- 必须通过图形验证码
- 同 IP 每日最多生成 3 次（可后台配置）
- 生成消耗管理员预设 KEY 的积分
- 不写入子用户池，仅入公共池
