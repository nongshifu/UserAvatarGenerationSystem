# 管理后台详细设计

> 技术栈：**原生 HTML + JS + CSS**，无框架无构建，可引入 Alpine.js / htmx（CDN 引入）增强交互  
> 部署路径：根域名 `/admin`，静态文件目录 `admin/`  
> 后端接口：`/admin-api/*`（由 backend 原生 PHP 提供）  
> 鉴权：登录成功后下发 JWT Token，存 localStorage，fetch 请求头携带 `Authorization: Bearer {token}`

---

## 一、布局结构

```
┌────────────────────────────────────────────┐
│ 顶部导航：LOGO │ 主题切换 │ 管理员 │ 退出       │
├──────────┬─────────────────────────────────┤
│          │                          │
│  侧边菜单  │       内容区域           │
│          │                          │
└──────────┴─────────────────────────────────┘
```

> 实现：`admin/index.html` 单页 + 侧边菜单切换中央内容区（通过 `fetch` 拉取对应 HTML 片段或直接渲染 JSON 到模板字符串）。表格、表单均原生手写；如需交互增强，CDN 引入 Alpine.js（3.x，~15KB）或 htmx（~14KB），不引入 Vue/React。

## 二、菜单与页面清单

### 2.1 仪表盘 `/dashboard`
- 统计卡片：今日生成量、今日注册、今日充值额、头像池总量
- 图表：近 7 天生成趋势、积分消耗趋势
- 待办：待审核订单数、待审核头像数

### 2.2 用户管理 `/users`
**列表**：
- 搜索：用户名/邮箱/手机号
- 筛选：角色、状态
- 列：ID、用户名、邮箱、角色、积分余额、状态、注册时间
- 操作：编辑、调整积分、禁用/启用、查看详情

**编辑弹窗**：
- 基础信息（昵称、头像、角色、状态）
- 积分调整（增加/扣减 + 备注，写入 point_logs）
- 重置密码

**详情抽屉**：
- 用户基本信息
- 积分余额与流水
- KEY 列表
- 生成记录
- 订单列表

### 2.3 开发者 KEY 管理 `/keys`
**列表**：
- 列：ID、所属用户、Key（脱敏）、名称、状态、QPS、日限额、今日用量、最后使用
- 操作：查看头像、查看子用户、重置Key、禁用/启用

**KEY 头像列表 `/keys/{id}/avatars`**：
- 该 KEY 下所有头像，支持按子用户筛选
- 可删除、设为/取消公共

**KEY 子用户管理 `/keys/{id}/sub-users`**：
- 子用户列表
- 点击查看某子用户头像历史

### 2.4 积分管理
**积分套餐 `/points/products`**：
- 商品 CRUD：名称、价格、积分、赠送积分、排序、上下架

**积分流水 `/points/logs`**：
- 全量积分变动记录
- 筛选：用户、类型、时间范围
- 列：用户、类型、变动值、余额、备注、时间

**手动调整 `/points/adjust`**：
- 选择用户 → 增加/扣减 → 备注 → 提交

### 2.5 订单管理 `/orders`
**列表**：
- 筛选：状态、支付方式、时间
- 列：订单号、用户、商品、金额、积分、状态、支付方式、下单时间
- 操作：查看、审核（确认到账/驳回）、备注、退款

**审核**：
- pending 状态可审核
- 确认到账 → 发放积分
- 驳回 → 关闭订单

### 2.6 生成与内容
**生成记录 `/generations`**：
- 全量生成记录
- 筛选：用户、KEY、状态、时间
- 可查看请求参数与响应

**预设提示词 `/prompts`**：
- CRUD：标题、提示词、分类、是否默认、排序、状态

**风格/颜色/形状配置 `/styles` `/colors` `/shapes`**：
- CRUD 表格，支持拖拽排序

**头像审核 `/avatars/audit`**：
- 审核开关状态展示
- 待审核头像列表
- 操作：通过（入公共池）/ 驳回（退积分）/ 删除

### 2.7 公共头像池 `/avatars/public`
- 公共池头像浏览
- 分类筛选（风格/颜色/形状）
- 批量操作：删除、取消公共

### 2.8 系统设置 `/settings`
**基础设置**：站名、LOGO、备案号、客服、统计代码

**SEO 设置**：各页面 TDK、OG 图、canonical

**积分设置**：注册赠送、默认消耗、最低阈值

**API 设置**：豆包 Key、模型、尺寸、水印

**审核设置**：总开关、自动入池、驳回退积分

### 2.9 操作日志 `/logs`
- 管理员操作审计
- 筛选：管理员、操作类型、时间

---

## 三、权限控制

- 仅 `role=admin` 可登录后台
- 菜单级权限：所有管理员可见全部菜单（单管理员模式，后续可扩展 RBAC）
- 所有写操作记录 `audit_logs`

---

## 四、接口前缀

所有后台接口前缀 `/admin-api`，与对外 API 隔离。
