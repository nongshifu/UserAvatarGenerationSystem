# 数据库详细设计

> 基于《项目大纲》第四章，细化所有表结构、字段类型、索引与关系。  
> 数据库：**MySQL 5.6**，字符集 utf8mb4，排序规则 utf8mb4_unicode_ci。  
> 所有表均包含 `created_at`、`updated_at` 时间戳（自写框架默认），软删除表额外包含 `deleted_at`。  
> 注意：5.6 不支持原生 JSON 函数，所有 `json` 类型字段改用 `text`，由代码层 `json_encode/json_decode` 处理。

---

## 一、ER 关系总览

```
users 1──N user_keys 1──N sub_users 1──N avatars
  │                                          │
  ├──N point_logs                            ├──N generation_records
  ├──N orders                                │
  └──N avatars (上传者)                       └── prompt_templates / styles / colors / shapes
                                                  
point_products 1──N orders
avatars ── (is_public) 公共池 / (key_id) KEY池 / (sub_user_id) 子用户池
```

## 六、缓存设计

| Key | 类型 | TTL | 说明 |
|-----|------|-----|------|
| `site_settings:{group}` | string(hash) | 1h | 站点设置分组缓存 |
| `avatar:random:pool` | set/list | 10min | 公共头像池随机样本 |
| `avatar:random:{style}:{color}` | set | 10min | 分类随机池 |
| `key:info:{hash}` | hash | 1h | KEY 信息缓存 |
| `user:balance:{id}` | string | 5min | 积分余额缓存 |
| `rate_limit:{key}:{sec}` | string | 1s | 秒级限流 |
| `rate_limit:{key}:{day}` | string | 1d | 日限额计数 |

## 七、初始数据（Seeder）

1. 创建超级管理员 `admin`（默认密码需首次登录修改）
2. 插入默认风格：卡通、Q版、赛博朋克、油画、水彩、像素风
3. 插入默认颜色：暖色、冷色、黑白、马卡龙
4. 插入默认形状：圆形、方形、无边框
5. 插入默认预设提示词：通用卡通化
6. 插入默认积分套餐：10元/100积分、30元/350积分、50元/600积分、100元/1300积分
7. 插入 site_settings 全部默认项
